# СМО — вариант 17

Простая программа для пошагового моделирования системы массового обслуживания.

На экране видно состояние **источников, буфера и приборов** после каждого шага.

## Запуск на Mac

Нужна **Java JDK 17 или новее**. Проверить установленную версию:

```bash
javac -version
```

Открой Терминал и выполни:

```bash
cd ~/Desktop/smo-coursework-var17/program
./run.sh
```

Программа соберётся и откроется автоматически.

## Как пользоваться

- **Следующий шаг** — выполнить одно действие и обновить состояние системы.
- **Сначала** — начать моделирование заново.
- **Настройки** — изменить параметры системы.

Всё: на каждом шаге можно посмотреть, какие заявки появились, что находится в буфере и какие приборы заняты.
