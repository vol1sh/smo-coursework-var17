# СМО, вариант 17 — простая пошаговая программа

Программа для демонстрации третьего этапа курсовой работы. **Java 17+, Swing, без зависимостей**.

## Как запустить

**macOS/Linux** — открыть терминал в папке проекта и выполнить:

```bash
chmod +x run.sh test.sh
./run.sh
```

**Windows** — запустить `run.bat` (требуется JDK 17+).

Если уже собран JAR, можно просто выполнить `java -jar smo-step3-minimal.jar`.

## Как пользоваться

- **Следующий шаг** или `Enter` — обработать ровно **одно** событие/действие и сразу обновить всё состояние.
- **Сначала** — начать ту же симуляцию заново (результат повторяем благодаря фиксированному seed).
- **Настройки…** — поменять число источников, приборов, размер буфера, интенсивность заявок, границы времени обслуживания, количество заявок или seed.

На экране **только три таблицы**: источники (сколько заявок создано, сколько отказов, время следующей заявки), буфер (каждая ячейка и указатели записи `З`/выборки `В`), приборы (занят или свободен, какая заявка обрабатывается, время завершения). Над таблицами — номер шага, текущее время, короткое описание последнего события и общие счётчики. **Календаря событий, графиков, длинного журнала и автоматического режима нет.**

Между двумя внешними событиями могут быть внутренние шаги диспетчеров с одинаковым модельным временем — это нормально: каждое нажатие показывает новое состояние после одного действия.

## Дисциплины варианта 17

`ИБ / ИЗ1 / ПЗ2 / Д1ОЗ1 / Д1ОО4 / Д2П1 / Д2Б3 / ОР1 / ОД2`

- `ИБ / ИЗ1`: бесконечные источники, экспоненциальные интервалы между поступлениями (пуассоновский поток).
- `ПЗ2`: равномерное время обработки на заданном интервале.
- `Д1ОЗ1`: постановка в буфер по кольцу.
- `Д1ОО4`: при переполнении выбивается **последняя записанная в буфер** заявка; новая занимает её место.
- `Д2П1`: первый свободный прибор в порядке номеров.
- `Д2Б3`: выборка заявки из буфера по кольцу.

Внутри модели используется очередь будущих событий, чтобы правильно переходить по модельному времени, но **она не отображается**: это внутренний механизм, а не таблица для пользователя. Нет внешних библиотек.

## Проверка

```bash
./test.sh
```

Тесты проверяют кольцевой буфер, выбивание, один шаг на нажатие, корректное завершение и повторяемость моделирования.
