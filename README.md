## 1. Формула варианта и ее расшифровка

| ИБ | ИЗ1 | ПЗ2 | Д1ОЗ1 | Д1ОО4 | Д2П1 | Д2Б3 | ОР1 | ОД2 |
|:--:|:---:|:---:|:-----:|:-----:|:----:|:----:|:---:|:---:|

* **ИБ** — Бесконечный источник заявок.
* **ИЗ1** — Пуассоновский закон генерации (экспоненциальные интервалы времени между заявками).
* **ПЗ2** — Равномерный закон времени обслуживания прибором.
* **Д1ОЗ1** — Дисциплина буферизации: заполнение буферной памяти «по кольцу» с указателем.
* **Д1ОО4** — Дисциплина отказа: при переполнении буфера выбивается **последняя поступившая в буфер заявка**.
* **Д2П1** — Дисциплина выбора прибора: с приоритетом по номеру (начиная с П1).
* **Д2Б3** — Дисциплина выбора заявки из буфера: выбор «по кольцу» с указателем.
* **ОР1** — Отражение результатов: сводная таблица статистических параметров.
* **ОД2** — Отображение динамики: формализованная схема с текущим состоянием узлов.

## 3. Первичные проектные артефакты

### 3.1. Сиквенс-диаграмма (Sequence Diagram)
* Исходный PlantUML-код: [`docs/sequence_diagram.puml`](docs/sequence_diagram.puml)
* Отражает: Happy Flow (прибор свободен), буферизацию по кольцу (Д1ОЗ1), выбивание последней заявки при переполнении (Д1ОО4) и выборку по кольцу (Д2Б3) на приоритетный прибор (Д2П1).

### 3.2. Диаграмма классов (Class Diagram)
* Исходный PlantUML-код: [`docs/class_diagram.puml`](docs/class_diagram.puml)
* Соблюдена строгая инкапсуляция и ООП: поля приватные, классы общаются через ссылки на смежные объекты (`RingBuffer`, `DeviceManager`, `StatisticsCollector`).

### 3.3. Flowchart с дорожками (Swimlanes Activity Diagram)
* Исходный PlantUML-код: [`docs/flowchart_swimlanes.puml`](docs/flowchart_swimlanes.puml)
* Показывает алгоритмическую логику прохождения заявок по дорожкам ответственности.
