## Вариант

| ИБ | ИЗ1 | ПЗ2 | Д1ОЗ1 | Д1ОО4 | Д2П1 | Д2Б3 | ОР1 | ОД2 |
|:--:|:---:|:---:|:-----:|:-----:|:----:|:----:|:---:|:---:|

- **ИБ** — бесконечный источник заявок.
- **ИЗ1** — пуассоновский поток (экспоненциальное время между заявками).
- **ПЗ2** — равномерное распределение времени обслуживания.
- **Д1ОЗ1** — заполнение буфера по кольцу с указателем записи.
- **Д1ОО4** — при переполнении выбивается последняя поступившая в буфер заявка.
- **Д2П1** — первый свободный прибор по возрастанию номера.
- **Д2Б3** — выбор заявки из буфера по кольцу с указателем чтения.
- **ОР1** — сводная таблица статистики.
- **ОД2** — формализованная схема текущего состояния системы.

Подробнее: [бизнес-домен и маппинг](docs/domain_mapping.md).
