### Что объяснять по Sequence

1. **Генерация (ИБ, ИЗ1):** источник создаёт заявку по событию календаря; следующий интервал экспоненциальный.
2. **Happy Flow (Д2П1):** если П1 свободен — заявка на П1. Если П1 занят, но П2 свободен — на П2.
3. **Все приборы заняты (Д1ОЗ1):** новая заявка записывается в свободную ячейку буфера по кольцу.
4. **Буфер полон (Д1ОО4):** вытесняется *последняя поступившая в буфер* заявка; новой выделяется её ячейка.
5. **Прибор освободился (Д2Б3, Д2П1):** календарь запускает выборку из буфера по кольцу; заявка назначается первому свободному прибору.
6. **Приборы не отказывают:** они либо заняты, либо свободны. Отказ получает заявка в буфере.

**Диспетчеры** — алгоритмы (объекты Java), а не люди. В реализации они являются вложенными классами `Simulation`.
